# Mutation Log

## Modified
- **hgai/core/rdf_import.py** — Imported `OWL` from `rdflib.namespace`. Added `_AXIOM_RELATION_OVERRIDES = {OWL.inverseOf: "owl:inverse-of"}`, used when building a resource-valued predicate's `relation` string (overriding the usual full-expanded-IRI rule for this one predicate, since HypergraphAI's inference engine recognizes the fixed, hyphenated string `"owl:inverse-of"` by exact match, never the real predicate's own CURIE `owl:inverseOf` or its full IRI). Added detection of `OWL.TransitiveProperty` in an entity's collected `rdf:type` values, which — in addition to the entity's normal `type`/`attributes.rdf_type` handling — synthesizes a single-member `hub` hyperedge (`relation: "owl:transitive"`, `members: [{node_id: <property's full IRI>, seq: 0}]`). Generalized `edge_tuples`'s shape from a fixed 2-member `(relation, subj_id, obj_id, sort_key)` tuple to `(relation, member_ids_tuple, sort_key)` so both the ordinary 2-member resource edges and the new 1-member transitive axiom edges share the same sort/build path. Updated the module's docstring with the new rule and its rationale.
- **docs/help/notes/web-ui/export-import.md**, **docs/api-reference.md** — Added two rows to the RDF mapping table for `owl:TransitiveProperty` and `owl:inverseOf`, linked to the Inferencing help topic, and a note that no other OWL/RDFS axioms are specially recognized.

## Created
- 8 new tests appended to **tests/test_rdf_import.py**: the transitive-property and inverse-of shapes match the request's own examples exactly; the relation string is confirmed to be the fixed HypergraphAI spelling regardless of the source file's own OWL prefix; both axioms combined on the same property; the inverse-of object still becomes its own hypernode; a non-transitive property gets no axiom edge; multiple `owl:inverseOf` values each get their own edge; and a full comparison against `scripts/seeds/hgai-hypergraph-eden.export.yml`'s hand-asserted `edge:child-trans`/`edge:parent-inv-child` shape.
