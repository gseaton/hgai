# Mutation Log

## Modified
- **ui/js/app.js** — Removed the binary-hyperedge special case from the Visualize tab's `renderViz()`: every hyperedge, regardless of member count, is now rendered as its own "bag" node (`henode` class) connected via standard `hspoke` edges to each member, instead of collapsing 2-member hyperedges into a plain undecorated line (the removed `hbinary` edge class/style). Spoke edges now carry `relation`, `seq`, and `raw` (the parent hyperedge) in their data, and bag node size scales with member count (`size = min(14 + arity*3, 40)`). Changed the `henode` Cytoscape shape from `diamond` to `round-rectangle` to read as a "bag". Generalized the `tap` handler from `'node'` to `'node, edge'` (guarded by `d.raw !== undefined`) so clicking a spoke edge — not just a bag or hypernode — opens the Element Details panel. Updated the `viz-stats` label from `"N nodes · M edges"` to `"N hypernodes · M hyperedges"` and dropped the now-unused `cy.edges('.hbinary')` count. Updated `buildVizLegend()`'s flavor swatch class from `diamond` to `bag`.
- **ui/css/hgai.css** — Replaced `.viz-legend-swatch.diamond` (rotated square) with `.viz-legend-swatch.bag` (small rounded rectangle) to match the new bag node shape in the legend.
