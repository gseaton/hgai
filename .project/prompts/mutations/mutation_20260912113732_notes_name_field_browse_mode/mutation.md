# Mutation Log

## Modified
- **hgai/models/note.py** — Added `name: str` (default `""`, max 200 chars, stripped via a new `_clean_name` validator) to `NoteBase`, and `name: Optional[str] = None` to `NoteUpdate`. `NoteInDB`/`NoteResponse`/`NoteCreate` all gain the field automatically via inheritance.
- **hgai/core/notes.py** — Added `"name"` to `NOTE_TRACKED_FIELDS` (mutation audit trail) and `name=dumped.get("name")` to `update_note`'s `NotePatch` construction.
- **hgai_module_storage/filters.py** — Added `name: Optional[str] = None` to `NotePatch`.
- **hgai_module_storage_mongodb/stores/notes.py** — Added `"name"` to the `update()` method's settable-field list, and a `name` clause to the `search` filter's `$or` (alongside `label`/`text`).
- **ui/index.html** — Restructured `#modal-note`: added a top-level Browse/Edit/Preview mode-bar (`.note-mode-bar`) between the header and body, replacing the old 2-button Edit/Preview toggle that lived inside the Content section. Added a new `#note-browse-view` block (Label heading, Name subtitle, rendered-content pane) shown only in Browse mode; the existing `<form id="form-note">` (Identity/Content/Classification/Media/History) is now hidden in Browse mode and shown in Edit/Preview. Added a `Name` input next to `Label` in the Identity section. Footer's Cancel button renamed to "Close" (more accurate once Browse is the typical, non-editing entry state). Added a `Name` column to the notes table header. Updated the search input's placeholder and the note-history section's help text is unchanged.
- **ui/css/hgai.css** — Added `.note-mode-bar` and `#note-browse-view`/`#note-browse-label` styling.
- **ui/js/app.js** — `setNoteMode(mode)` rewritten for three modes (`browse`/`edit`/`preview`) instead of two, toggling `#note-browse-view` vs `#form-note` visibility and rendering into `#note-browse-content` when entering Browse; a new `noteModalEditable` module-level flag (set in `openNoteModal`) gates Save's visibility across all three modes and whether the "Edit" mode button itself is shown at all. `openNoteModal` now populates/reads `note-name`, defaults to Browse mode for an existing note (Edit for a brand-new one), and hides the Edit-mode button entirely when the viewing account can't edit. `setNoteFieldsDisabled` gained `note-name`. The note-internal-link click handler (previously only on `#note-preview`) is now also attached to `#note-browse-content` via a shared `noteInternalLinkClickHandler`. `loadNotes()`'s table row rendering gained a Name `<td>`, and `colspan` values bumped from 7 to 8. `buildNoteFolderTree`/`renderNoteFolderNode` changed to sort and display by `name || label` instead of `label` alone, showing `label` as disambiguating meta context when `name` is set.
