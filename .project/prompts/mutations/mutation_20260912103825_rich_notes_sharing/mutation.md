# Mutation Log

## Created
- **hgai/models/note.py** — `NoteRole` (viewer/editor), `NoteGrant` (username+role), `NoteBase`/`NoteCreate`/`NoteUpdate`/`NoteInDB`/`NoteResponse`, `ShareNoteRequest`. A Note carries `label`, `text` (Markdown), `media: List[MediaRef]`, plus the standard `tags`/`status`/`attributes`/`system_created`/`system_updated`/`created_by`/`version` from `TimestampedModel`, and its own `id` (uuid4 hex), `owner_username`, `acl: List[NoteGrant]`, `mutations: List[MutationRecord]`.
- **hgai/core/mutations.py** — `is_blank`, `create_delta`, `update_delta`, `append_mutation`: the mutation-audit-trail helpers, extracted verbatim from `hgai/core/engine.py` (which previously defined them as "private" `_`-prefixed module functions) into their own shared module so `hgai/core/notes.py` can reuse the exact same semantics without reaching into another module's private internals.
- **hgai/core/notes.py** — Note engine: `NOTE_TRACKED_FIELDS`, `can_view_note`/`can_edit_note` (pure permission checks: owner always full access; an ACL entry grants view always, edit only if role=editor), `create_note`, `get_note`, `list_notes_visible_to`, `update_note`, `delete_note`, `share_note` (idempotent grant/replace, comparing ACL as a set of (username, role) pairs so reordering from the remove-then-append pattern doesn't spuriously trigger a mutation), `unshare_note` (no-op if the account had no grant).
- **hgai/api/routers/notes.py** — REST router (`/notes`): list (visible-to-caller, paginated, tag/search filters), create, get, update, delete (owner/admin only), `GET/POST /notes/{id}/share` (list grants / grant-or-change), `DELETE /notes/{id}/share/{username}` (revoke). Every route requires authentication; view/edit/owner-only checks are inline (fetch once, check, proceed) rather than a FastAPI dependency, since — unlike graph-nested resources — a note has no path-injected parent id to key a dependency off of.
- **hgai_module_storage_mongodb/stores/notes.py** — `MongoNoteStore`: create/get/list (visibility clause: `owner_username == username OR acl.username == username`, tag/search filters via an explicit `$and` of clauses)/update/delete.
- **tests/test_notes.py** — 8 unit tests for `can_view_note`/`can_edit_note` (owner, stranger, viewer-grant, editor-grant, multi-grant independence). `create_note`/`update_note`/`share_note`/etc. are storage-backed and verified live instead, per this project's established testing convention.
- **.project/prompts/mutations/mutation_20260912103825_rich_notes_sharing/** — this capture.

## Modified
- **hgai_module_storage/filters.py** — Added `NoteFilters` (username/tags/search/status/sort) and `NotePatch` (label/text/media/tags/attributes/status/acl/mutations) dataclasses.
- **hgai_module_storage/backend.py** — Added `NoteStore` ABC (create/get/list/update/delete — sharing goes through the same generic `update()`, not dedicated store methods) and a `notes` property on `StorageBackend`. Imports `NoteFilters`/`NotePatch`.
- **hgai_module_storage_mongodb/backend.py** — Wired `MongoNoteStore` into `MongoStorageBackend` (`self._notes`, `notes` property).
- **hgai_module_storage_mongodb/indexes.py** — Added `notes` collection indexes: unique `id`, `owner_username`, `acl.username`, `tags`.
- **hgai/core/engine.py** — Removed its local `_is_blank`/`_create_delta`/`_update_delta`/`_append_mutation` definitions; now imports them from the new `hgai.core.mutations` module under their original names (`from hgai.core.mutations import append_mutation as _append_mutation`, etc.), so every existing call site and `tests/test_engine.py`'s direct imports keep working unchanged. `HYPERNODE_TRACKED_FIELDS`/`HYPEREDGE_TRACKED_FIELDS` stay in `engine.py` (resource-specific, not shared).
- **hgai/main.py** — Registered `notes.router` under `/api/v1`.
- **ui/js/api.js** — Added `listNotes`, `getNote`, `createNote`, `updateNote`, `deleteNote`, `listNoteShares`, `shareNote`, `unshareNote`.
- **ui/index.html** — New "Notes" sidebar link; `#screen-notes` (search/tag-filter bar, paginated table: Label/Tags/Owner/Shared With/Updated/Status/actions); `#modal-note` (Identity, Content with Edit/Preview toggle, Classification, Media, read-only History sections, a "Share" button in the header); `#modal-note-share` (owner display, per-grant rows with revoke, add-grant form). Added `marked@12.0.2` and `dompurify@3.1.5` CDN script tags.
- **ui/js/app.js** — `showScreen`'s `titles`/loader maps gained `notes`; `PAGINATION_LOADERS` gained `notes`; `State` gained `notesPage`/`notesPageSize`. New Notes section: `loadNotes`, `deleteNoteRow`, `renderNoteMarkdown`/`resolveNoteMediaEmbeds` (Markdown rendering with `note:`/`media:` custom-scheme resolution), `setNoteMode` (Edit/Preview toggle), `openNoteModal`/`setNoteFieldsDisabled` (view-only lockdown for viewer-role accounts), `openNoteShareModal`/`loadNoteShares` and their button wiring. `renderMediaList`'s default-media-star toggle is now derived from `defaultMediaState(containerId)` returning `null` for `'note-media-list'` (Notes have no `default_media_id` concept) instead of a boolean parameter every call site would have needed to remember.
