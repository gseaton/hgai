# Mutation Log

## Modified
- **hgai/models/hypernode.py** — Added `default_media_id: Optional[str]` to `HypernodeBase` (points at one of the entity's own `media` list entries) and to `HypernodeUpdate`.
- **hgai/models/hyperedge.py** — Same for `HyperedgeBase`/`HyperedgeUpdate`.
- **hgai/core/media.py** — Added `validate_default_media_id(default_media_id, media_refs) -> str`: returns the id unchanged if it matches an entry in `media_refs`, otherwise `""` (the "no default" sentinel — see rationale in the docstring and in `summary.md`).
- **hgai/core/engine.py** — `create_hypernode`/`update_hypernode`/`create_hyperedge`/`update_hyperedge` now run `default_media_id` through `validate_default_media_id` against the entity's effective (new-or-existing) `media` list before persisting, and `update_*` thread it into `HypernodePatch`/`HyperedgePatch`.
- **hgai_module_storage/filters.py** — Added `default_media_id: Optional[str]` to `HypernodePatch` and `HyperedgePatch`.
- **hgai_module_storage_mongodb/stores/hypernodes.py** / **stores/hyperedges.py** — `update()` now includes `default_media_id` in the set of patchable attributes.
- **ui/index.html** — Node/edge Media section: no markup change needed (star toggle button added purely in the JS row template). Nodes and Edges screens: added a "Show media" switch each, and a `Media` `<th>` (hidden by default via `d-none`) positioned right after ID. Media Association edit modal: unchanged this turn. Visualize screen: added a "Media" switch alongside the existing "Labels" switch.
- **ui/js/app.js** — `renderMediaList()` gained a star/toggle button per media item (filled amber star = current default, outline = not) via a new `defaultMediaState(containerId)` helper that maps the container to `nodeDefaultMediaId`/`edgeDefaultMediaId` module state; removing the current default item clears it. `openNodeModal()`/`openEdgeModal()` populate/reset that state on open; `btn-save-node`/`btn-save-edge` include it in the save payload. Added `defaultMediaRefFor()`, `mediaThumbCellHtml()`, and `loadTableThumbnails()` (with `_nodeThumbUrls`/`_edgeThumbUrls` object-URL tracking) and wired them into `loadNodes()`/`loadEdges()` behind the new "Show media" checkboxes. Added `vizMediaEnabled`, `vizThumbNodeEls`, `_vizThumbUrls`, `vizDefaultMediaRefFor()`, and `vizLoadThumbnails()`; extended `vizBuildLabelLayer()`/`vizClearLabelLayer()`/`vizLabelTick()` to build, position, and clean up thumbnail `<img>` overlays for hnode/henode entries with an image-typed default media, independent of the existing label toggle.
- **ui/css/hgai.css** — Added `.media-item.media-item-default` (amber highlight for the designated item in the attachment widget), `.table-thumb` (Nodes/Edges table thumbnail sizing), and `.viz-thumb` (3D visualization DOM-overlay thumbnail styling, positioned like `.viz-label` but nudged above it).
