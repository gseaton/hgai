# Mutation Log

## Modified
- **hgai/core/inference.py** — Removed `infer_inverse_edges()` (fully superseded, zero callers, naive `list(reversed(members))` logic was actually wrong for multi-member `hub` edges). Added:
  - `_member_ids(edge)`, `_other_member(axiom_edge, relation_id)` (order-irrelevant binary-axiom lookup; returns `None` unless `relation_id` is actually one of the edge's members — a bug found and fixed via a unit test that caught it returning an arbitrary member instead), `_make_inferred_edge(...)` — small pure helpers.
  - `_atomic_facts(edge)` — decomposes an edge into its individual `(relation, subject, object)` facts via `atomic_pairs`; replaces an earlier, incorrect `_edge_content_key` (whole-edge relation+members identity) that was found live-testing to under-dedupe (see summary).
  - `expand_edge(edge, graph_ids, pit=None)` — single-pass axiom-driven expansion: `owl:inverse-of`, `owl:symmetric`, and superproperty projection via `skos:narrowerTransitive`/`broaderTransitive` (using `walk_closure`, so a multi-hop relation hierarchy projects through every level in one call).
  - `expand_edge_closure(fact_edges, graph_ids, pit=None, max_iterations=10)` — fixed-point closure repeatedly applying `expand_edge` to the growing frontier, deduping by atomic-fact-set membership (not whole-edge identity) so a fact re-derived under a different member-bundling shape is correctly recognized as already known.
  - Updated module docstring: `expand_edge`/`expand_edge_closure` are now wired into HQL; `check_transitive_relation` still isn't (Step 4).
- **hgai_module_hql/engine.py** — `execute_hql()`: parses a new top-level `infer: true` HQL flag; when set and hyperedges are matched, runs `expand_edge_closure` over the matched fact edges and appends the synthesized (`_inferred: true`-tagged) edges to the result, subject to the same `return:` field projection as any other item. `infer` also surfaced in the result `meta`. A query with no `infer` flag never calls into the reasoning engine at all (verified).
- **tests/test_inference.py** — Removed the two tests for the replaced `_edge_content_key`; added tests for `_member_ids`, `_other_member` (including the bug found: returning `None` when the queried id isn't actually a member), `_make_inferred_edge`, and three tests for `_atomic_facts` (list-order independence, cross-relation distinction, and the specific "same facts bundled two different ways must produce the same fact set" property that fixed the live bug).
