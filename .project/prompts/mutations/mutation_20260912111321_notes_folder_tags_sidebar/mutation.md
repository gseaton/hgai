# Mutation Log

## Modified
- **ui/index.html** — Restructured `#screen-notes`'s content into a two-pane `.notes-layout` (matching Quill's own page layout: a folder sidebar next to the main content): a new `.notes-folder-sidebar` `<aside>` (header with "Folders" title + Expand All/Collapse All buttons, and an empty `#notes-folder-tree` container) placed before the existing `.notes-main` div, which now wraps the pre-existing search/filter bar and notes table unchanged. Updated the note editor's Tags field help text to mention that a `//`-prefixed tag places the note in that folder.
- **ui/js/app.js** — `showScreen`'s `notes` loader now also calls `loadNotesFolderTree()`. Added a new "Notes folder sidebar" section: `parseNoteFolderSegments` (parses a `//a/b/c` tag into `["a","b","c"]`, or `null` if not a folder tag), `buildNoteFolderTree` (merges every visible note's `//`-tags into a nested tree, case-insensitive segment matching keeping first-seen casing, deduped per note per folder), `renderNoteFolderNode`/`renderNoteFolderTree` (renders the tree as nested `<details>`/`<summary>` elements, sessionStorage-backed open/closed persistence, top-level expanded/nested collapsed by default), `loadNotesFolderTree` (fetches up to 200 visible notes — independent of the main table's search/filter/pagination state — and rebuilds the tree), and the Expand All/Collapse All button handlers. `btn-refresh-notes`, `btn-save-note`'s create/update success path, and `deleteNoteRow`'s success path all now also call `loadNotesFolderTree()` so the tree stays in sync with tag changes.
- **ui/css/hgai.css** — Added `.notes-layout`/`.notes-folder-sidebar`/`.notes-main` (flex two-pane layout, sidebar sticky with independent scroll) and `.notes-folder-*` rules (tree/node/label/icon/name/note-item/empty-state styling), including the pure-CSS open/closed folder-icon swap keyed off `<details>`'s native `[open]` attribute (blue `bi-folder2-open` when open, amber `bi-folder2` when closed) — no JS needed just to flip which icon shows.
