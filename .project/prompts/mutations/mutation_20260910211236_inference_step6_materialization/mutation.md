# Mutation Log

## Modified
- **hgai/core/inference.py** — Added `project_inference(source_graph_ids, target_graph_id, mode, relation=None, pit=None, projected_by="system", target_space_id=None)`: the one write-capable function in this module. `mode="expand"` runs `expand_edge_closure` over source fact edges (optionally filtered to `relation`); `mode="transitive"` (requires `relation`, self-gated on an `owl:transitive` axiom) materializes every non-1-hop node transitively reachable from each subject of that relation; `mode="both"` runs both. Every candidate is checked against `engine.find_duplicate_hyperedge` before writing (skipped if already materialized) and, if new, written through the ordinary `engine.create_hyperedge` path with `attributes.provenance` recording `source_graphs`, `source_edge`, `axiom`, `pit`, `projected_by`, `projected_at`. Returns `{created, skipped, errors, error_details, edges}`.
- **hgai/api/routers/inference.py** — Added `POST /graphs/{graph_id}/infer/project` (the `graph_id` path segment is the *target*): request body `{source_graph_ids, mode, relation?, pit?, create_target?, target_label?}`. Verifies read access to every listed source graph (in addition to the existing `require_graph_access("write")` dependency guarding the target); creates the target hypergraph first if `create_target: true` and it doesn't already exist; delegates to `project_inference`; `ValueError`s from invalid `mode`/missing `relation` become clean `400`s rather than raw exceptions.
