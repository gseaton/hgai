# Mutation Log

## Modified
- **ui/index.html** — Swapped the `cytoscape@3.30.2` CDN `<script>` for `3d-force-graph@1.80.0`. Removed the 2D-only "Layout" `<select>` (cose/concentric/breadthfirst/circle/grid — meaningless for a physics-based 3D force graph) and the "Labels" always-on-label switch, replacing them with an "Auto-rotate" switch (`#viz-auto-rotate`). Renamed the render container from `#cy` to `#viz-canvas`. Updated the empty-state and detail-panel copy to mention links (`"Click a node, hyperedge, or link to inspect it"`) and 3D rendering.
- **ui/css/hgai.css** — Changed `#viz-cy-wrapper` background from white to dark (`#0f0f1a`, matching the sidebar/login dark theme) to suit a 3D scene; renamed the `#cy` selector to `#viz-canvas` and added a rule so its injected `<canvas>` displays as `block`; lightened `.viz-empty-state` text color for contrast against the dark canvas.
- **ui/js/app.js** — Replaced the entire Cytoscape-based "Visualize" module with a `3d-force-graph`-based one (`State.vizCy` renamed to `State.viz3d`). `renderViz()` now builds, per hyperedge, exactly the structure diagrammed in `docs/architecture/hypergraph-3d-viz.md`: a hyperedge node, a virtual "hyperedge" link to a virtual "members" node, and one relation-labeled link per member from that "members" node to the member's hypernode — regardless of arity, replacing the previous "bag with direct spokes" model. Added `initViz3D()` (ForceGraph3D setup: node/link color/size/label accessors, click-to-focus-camera on node click, click handlers for both nodes and links that route to `vizShowDetail()`), `vizResizeCanvas()` (sizes the WebGL canvas to its flex container and re-runs on window resize), `vizShowDetail()`/`vizClearDetail()`, `vizEsc()` (HTML-escapes node/link hover-tooltip content), `vizRecomputeDim()` (dim/highlight bookkeeping shared by search and legend toggling, since per-node/per-link opacity accessors aren't available in this library — dimming is done via a muted color swap plus re-invoking the existing color accessors to force a repaint), and `vizStartAutoRotate()`/`vizStopAutoRotate()` (a slow camera orbit around the current view radius, gated on the Visualize screen being active). `fetchGraphElements()`, `populateVizGraphSelect()`, `loadVizScreen()`, `vizColorForType()`, and the flavor/type color palettes are unchanged from the prior mutation. Removed `runVizLayout()` (no 3D equivalent) and the old label-toggle listener.
