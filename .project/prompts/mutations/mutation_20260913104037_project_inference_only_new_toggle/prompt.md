# Prompt

Please add the functionality to the 'Project Inference' action to include a control 'Project only new hyperedges?' toggle that if enabled, the project inferences does NOT generate / create new  'missing' hyperedges/hypernodes in the target projected hypergraph. The reasoning is that when a user / agent composes hypergraphs for query or other operations, the references in the inferred hyperedge-only projected that is also composed, will reference the original hyperedges/hypernodes in their original canonical hypergraph locations and NOT the generated / duplicated at the point of projected inferencing copies of already existing canonical hypergraphs.  However, maintain the ability (when the 'Project only new hyperedges?' toggle is off to be able to project and generate a 'snapshot' completely self-contained with both explicit and inferred hyperedges.
