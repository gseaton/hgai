# Mutation Log

## Modified
- **hgai/core/inference.py** — `project_inference()` gained an `only_new_hyperedges: bool = False` parameter. Added a new closure, `_resolve_member_ref(node_id)`, that resolves a candidate edge's member id to what should actually be written into the target graph: unchanged if it already exists in the target (as a hypernode or hyperedge), graph-qualified (`<source_graph_id>.<node_id>`) if it's found in one of the source graphs instead, or unchanged (dangling) if found nowhere — cached per id, mirroring the existing `_ensure_member_exists` helper's structure but never writing anything. The main per-candidate loop now computes a `resolved_members` list via this resolver when `only_new_hyperedges` is set (otherwise using the candidate's raw members, unchanged from before), and uses those resolved ids consistently for both the `find_duplicate_hyperedge` dedup check and the final `HyperedgeCreate` — the existing `_ensure_member_exists`-driven duplication loop is skipped entirely when `only_new_hyperedges` is set. Updated the docstring to document the new parameter and clarified that `preview`/`entry.members` now reflects the actual (possibly graph-qualified) ids that would be/were written.
- **hgai/api/routers/inference.py** — `ProjectInferenceRequest` gained an `only_new_hyperedges: bool = Field(default=False, ...)` field, passed through to `project_inference()` in the `/graphs/{graph_id}/infer/project` handler.
- **ui/index.html** — Added a "Project only new hyperedges?" checkbox (`#pi-only-new-hyperedges`) to the Project Inference screen, as its own callout row (with inline explanation of both states) below the existing 3-column source/mode/target form and above the Preview/Confirm buttons.
- **ui/js/app.js** — Added `pi-only-new-hyperedges` to the list of inputs whose `change` event invalidates a previously-run preview (disables Confirm & Project until a fresh Preview). `piBuildRequest()` now reads the checkbox and includes `only_new_hyperedges` in the request body sent to `HGAI_API.projectInference()`.
