# Mutation Log

## Modified
- **ui/js/app.js** —
  - Replaced the per-flavor color map (`VIZ_FLAVOR_COLOR`, `VIZ_MEMBERS_COLOR`) with fixed edge-kind colors matching the reference image: `VIZ_LINK_HYPEREDGE_COLOR` (`#be185d`, magenta, for hyperedge→members links) and `VIZ_LINK_RELATION_COLOR` (`#f59e0b`, amber, for members→member links); renamed the neutral node color to `VIZ_STRUCTURAL_COLOR`. Added `VIZ_LAYER_Y` (`{ henode: 160, members: 0, hnode: -160 }`), the target world-Y for each node kind.
  - Added `vizLayerForce()`, a custom d3-force (`initialize(nodes)`/`force(alpha)` contract) that gently pulls every node's Y toward its kind's `VIZ_LAYER_Y` value each simulation tick; wired into the graph via `.d3Force('layer', vizLayerForce())` in `initViz3D()`.
  - `renderViz()`: the hyperedge node (`henode`)'s `label` now comes from the hyperedge's own `label`/`id`/`hyperkey` (matching the reference diagram's top box, which shows the hyperedge's own id) instead of its relation string; its `color` is now the neutral `VIZ_STRUCTURAL_COLOR` instead of a flavor color; the hyperedge's `relation` is now stored as a separate field for the hover tooltip. The "hyperedge" link's color is now the fixed `VIZ_LINK_HYPEREDGE_COLOR`; each "relation" link's color is now the fixed `VIZ_LINK_RELATION_COLOR`. Removed the `flavorSeen` tracking set (no longer needed).
  - `buildVizLegend()`: dropped the per-flavor swatch list; added a fixed two-entry "edge kind" key (`flavor/* edge` in magenta, `rel:* edge` in amber) shown whenever at least one hyperedge is rendered. Call site updated from `buildVizLegend(typeCount, flavorSeen)` to `buildVizLegend(typeCount, hyperedgeCount > 0)`.
  - `vizBuildLabelLayer()`: node-label elements for `members`-kind nodes get an additional `viz-label-virtual` CSS class; link-label elements get their inline `color` set from the link's own `color` field (so flavor-links render in magenta text, relation-links in amber text).
  - Updated the `henode` hover tooltip to show `relation · flavor:<flavor> · N members` instead of just `hyperedge · <flavor> · N members`.
- **ui/css/hgai.css** — Restyled `.viz-label-node` as a rounded-rectangle "box" (light background, dark text, border, subtle shadow) to match the reference diagram's node style, replacing the previous plain drop-shadowed text; added `.viz-label-node.viz-label-virtual` (green text/border) for the "members" virtual node, echoing the diagram's green-highlighted "members" text; `.viz-label-link` is now bold with a strong drop shadow (color is set per-element in JS, not in CSS, so it can vary by edge kind).
