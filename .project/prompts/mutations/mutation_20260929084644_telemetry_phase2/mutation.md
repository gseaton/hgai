# Mutation Log

## Created
- **hgai_module_telemetry/errors.py** — `templatize_message` (redacts quoted segments so same-shape errors with different data share a fingerprint), `stack_frames` (repo-relative file:line:function only, no source text, stdlib/site-packages frames dropped), `fingerprint` (sha256 of type+innermost-repo-frame+template), `build_error_event` (the `kind: "error"` record, plan §3/§7).
- **hgai_module_telemetry/routing.py** — `route_template(scope)` (moved out of middleware.py so exception handlers can reuse it without importing the middleware) and `request_start(scope)` (reads the timestamp the middleware stashes).
- **hgai_module_telemetry/rest_errors.py** — `report(request, exc, http_status)`: builds and emits a REST-layer error event; skips `401` (routine auth-denial noise, not a bug) with the carve-out documented in code; never raises.
- **tests/test_telemetry_errors.py** — 18 tests: `templatize_message`/`stack_frames`/`fingerprint`/`build_error_event` unit tests, and REST exception-handler integration tests (404/403/401/500 cases, response-body-unchanged assertions, and error-reporting-never-raises).
- **tests/test_telemetry_shql.py** — 12 tests (parametrized over the reference and real-MongoDB backends, reusing `tests/storage_fixtures.py`) proving `execute_shql`'s telemetry wrapper is transparent (identical return value / raised exception) and reports the right usage/error events, including the aggregate-pushdown attributes and a permission-denial outcome.

## Modified
- **hgai_module_telemetry/middleware.py** — Uses the extracted `route_template` from `routing.py`; stashes `telemetry_start` on `scope["state"]` so the exception handlers can report a real `duration_ms`.
- **hgai_module_shql/engine.py** — Added `import logging` + module `logger`; renamed the existing `execute_shql` body to `_execute_shql_impl` (unchanged); added a new thin `execute_shql` wrapper that times the call, emits a `usage` event (with SHQL-specific attributes: aggregate/pushdown/paging/truncated/infer/cached/federated/pattern kinds) on success or an `error` event on failure, then returns/re-raises exactly as before. Added `_shql_telemetry_flags`, `_emit_shql_usage`, `_emit_shql_error` helpers (lazy-imported, broadly caught, matching the module's existing optional-dependency convention for `hgai_module_mesh`).
- **hgai/main.py** — Registered `@app.exception_handler(HTTPException)` and `@app.exception_handler(Exception)`, both reporting through `hgai_module_telemetry.rest_errors.report` and then returning exactly FastAPI's/Starlette's own default response (delegating to `fastapi.exception_handlers.http_exception_handler` for the first, replicating `ServerErrorMiddleware`'s `PlainTextResponse("Internal Server Error", 500)` for the second) — registered conditionally, non-fatal, matching every other optional module.
