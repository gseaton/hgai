# Mutation Log

## Modified
- **hgai/models/media.py** — Added `duration_seconds: Optional[float]` to `Media`. Added `name`, `label`, `size_bytes`, `duration_seconds` (all `Optional`) to `MediaRef`, so a node's/edge's cached attachment reference can carry these for display without a round-trip (not yet consumed by the UI — see Pending below).
- **hgai/core/media.py** — Added `extract_media_duration(content_type, data) -> Optional[float]`: best-effort audio/video duration via `mutagen`, returns `None` for non-audio/video content, unrecognized formats, or any extraction error.
- **hgai_module_storage_mongodb/stores/media.py** — `put()` now buffers bytes alongside the GridFS stream-through *only* for audio/video content types, and computes `duration_seconds` via `extract_media_duration` after upload. `list()`'s sort is now driven by `filters.sort` (falling back to `system_created` descending) instead of a hardcoded sort.
- **hgai_module_storage_mongodb/stores/media_s3.py** — Same two changes as `stores/media.py` (this store already buffers the full body in memory, so duration extraction needed no extra buffering there).
- **hgai_module_storage/filters.py** — Added `sort: Optional[List[Tuple[str, int]]]` to `MediaFilters`.
- **hgai/api/routers/media.py** — Added `MEDIA_SORT_FIELDS` and a `sort` query param to `GET /media`, validated via the existing `parse_sort_param` helper and threaded into `MediaFilters`.
- **requirements.txt** / **pyproject.toml** — Added `mutagen` as a dependency.
- **ui/index.html** — Media catalog table: header now reads File | Name | Label | Type | Size | Duration | Refs | Uploaded By | Tags | Status | (actions) — Size and Duration are now separate columns (previously combined into one "Size / Duration" column), and all sortable columns (all but Tags and the action column) carry `sortable-th`/`data-table="media"`/`data-sort-field`/`sort-indicator` markup matching the existing Nodes/Edges sortable-header pattern.
- **ui/js/app.js** — `fmtDuration()` now always renders `H:MM:SS` (previously omitted the hours segment for sub-hour durations). `loadMedia()`'s row template renders Name and Label as plain escaped text with no `truncate()`/`text-truncate-150` clipping, and Size/Duration as two separate `<td>`s (Duration cell is `fmtDuration(...) || '-'`). `State.mediaSort` added; `loadMedia()` sends `sort: sortParam(State.mediaSort)` and calls `updateSortIndicators('media')`. `handleSortableThClick()`'s per-table reload dispatch was generalized to look up `PAGINATION_LOADERS[table]` instead of a hardcoded `nodes`/`edges` if/else, which is what makes the Media table (and any future sortable table) work via the same click handler with no table-specific code. Bumped the Media table's hardcoded `colspan` (10→11 in three places) for the new Duration column.

## Pending (not part of this mutation)
The hyperedge/hypernode "associated media" attachment-list widget (`renderMediaList` in `ui/js/app.js`, used inside the node/edge create/edit modals) was **not** updated to display name/label/type/duration/size — Turn 2's fixes were scoped entirely to the standalone Media catalog table, so this part of Turn 1's original request is still open. `MediaRef` was already extended with the necessary cached fields (see above) in anticipation of that follow-up.
