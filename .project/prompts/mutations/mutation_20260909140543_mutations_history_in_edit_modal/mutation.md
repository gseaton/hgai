# Mutation Log

## Modified
- **ui/index.html** — Added a new, initially-hidden "History" section (`node-form-section-last d-none`, id `node-history-section`, containing `<div id="node-mutation-history">`) as the new last section of the Hypernode edit modal, after Attributes (which lost its `node-form-section-last` class since History now takes that role). Added the identical structure (`edge-history-section` / `edge-mutation-history`) as the new last section of the Hyperedge edit modal.
- **ui/js/app.js** — Generalized `renderMutationHistory(mutations, containerId, { showHeading })` (previously hardcoded to the View modal's `modal-detail-history` container) to accept a target container id and an option to suppress its own "Mutation History (N)" heading — used when the surrounding section (the edit modals' "History" section) already provides one. `showDetail()` updated to call it with its previous defaults (no behavior change there). `openNodeModal()` now hides/clears `node-history-section` by default at the top of the function, then shows it and calls `renderMutationHistory(n.mutations, 'node-mutation-history', { showHeading: false })` only inside the true edit (`isEdit`) branch — never for create or clone, since a clone is a brand-new record with no history of its own. `openEdgeModal()` gets the identical treatment for `edge-history-section` / `edge-mutation-history`.
