    Project Inference
    
        
    
        
    
          Materialize inference results (inverse-of/symmetric/superproperty expansion, and/or transitive closure)
          from source hypergraph(s) into a target hypergraph as ordinary, persisted facts. Computed live and
          previewed before anything is written — this is a snapshot, not a live sync: re-running later only adds
          new facts, it never removes or updates ones already materialized.
        
    

        
    
          
    
            
    
              
    
                
                
                
    Ctrl/Cmd-click to select multiple
    
              
    

              
    
                
                
    
                  
                  
                
    
                
    
                  
                  
                
    
                
                
                
              
    

              
    
                
                
    
                  
                  
                
    
                
    
                  
                  
                
    
                
                
    
                  
                  
                
    
              
    
            
    

            
    
              
              
              
    
                On: a projected edge's members that don't already exist in the target aren't duplicated into
                it, and aren't rewritten either — they're left exactly as they appear in the source, so the
                target stays a thin, inference-only layer meant to be queried alongside the source(s)
                (a multi-graph query, or a logical graph composing both), where those references resolve on
                their own.
                Off (default): missing members are copied into the target, producing a fully self-contained
                snapshot with both explicit and inferred hyperedges.
